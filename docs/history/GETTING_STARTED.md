# docs/GETTING_STARTED.md 변경 이력

이 문서는 `docs/GETTING_STARTED.md`에 일어난 변경을 날짜순(최신 먼저)으로 기록한다.

## 2026-10-25 — 최초 작성

- v0.1 무료 티어(cardea) 범위의 기능 전체를 단계별(0~10단계)로 그려, 처음 쓰는
  개발자가 각 기능에 어떻게 접근하는지 상세화했다. 아직 구현 전이라 명령어(`cardea
  init`, `cardea connect` 등)는 검증용 가설이며 확정 스펙이 아니다.
- "설치부터 첫 보호까지 5분" 목표를 단계별 예상 시간으로 검증 — 필수 경로(0→3단계)는
  약 4분으로 목표 안에 들어오나, NoPII(SDK `base_url` 한 줄 교체)보다 단계가 많다는
  구조적 약점을 발견했다.
- 발견한 개선 과제 6개를 문서 끝에 정리했다(원스텝 퀵스타트 명령, 연결 변경 가시성·
  되돌리기, 미리보기를 대화형 전용으로 좁히기, 에이전트 거버넌스 단계적 노출, 서명
  검증 실패 시 사유 설명, 설치 스크립트의 플랫폼별 분기 확인).

## 2026-10-25 (3차) — "한국형" 표현 제거

- "기본 한국형 탐지 룰팩"을 "기본 민감정보 탐지 룰팩(한국 민감정보 유형 포함)"으로
  바꿨다(1단계 목록, 완료 출력 예시). 사용자 지시: 프로젝트 목표를 "글로벌 표준으로
  개인정보·민감정보를 외부로 유출하지 않는 것"으로 명문화.

## 2026-10-25 (2차) — 사용성 개선 반영 개정

- 1차 드래프트의 개선 과제 6개를 흐름에 직접 반영했다.
  1. `cardea init`+`cardea connect` 2단계를 `cardea quickstart <tool>` 1단계로 합쳐
     1단계로 재작성(기존 2단계는 "세부 설정" 경로로 유지).
  2. 2단계를 "연결 내역 확인/되돌리기"(`--show-changes`, `disconnect`) 전용으로
     분리해 신설.
  3. 3단계의 마스킹 안내를 "최초 1회만" 배너로 좁히고, 전송 전 미리보기(FR-PI-05)를
     `cardea chat --preview-before-send`로 대화형 CLI 전용 옵트인으로 명시.
  4. 5단계(에이전트 거버넌스)를 "기본 화면 2개(세션 오염 배지, 예산) + 고급 설정
     4개"로 단계적 노출 구조로 재작성.
  5. 8단계(플러그인 설치) 서명 검증 실패 시 출력 예시에 실패 이유·안전 조치·상세
     확인 명령을 명시.
  6. 0단계 설치 명령에 macOS/Linux/WSL과 Windows 네이티브 PowerShell을 나란히
     제시하고 자동 감지 실패 시 안내를 추가.
- 타임라인을 재계산: 필수 경로가 4분에서 약 2분 30초로 줄었다.
- "검증 필요 사항" 절을 신설해, 반영이 끝났으므로 남은 건 실제 구현 시 확인할
  3개 항목(설치 자동 감지 실패율, quickstart 질문 최소화 여부, 기본/고급 분리의
  실제 효과)으로 좁혔다.
