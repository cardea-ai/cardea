# docs/history

`docs/` 아래 각 문서의 변경 이력은 본문에 날짜 태그로 섞지 않고, 이 디렉터리에 문서와
같은 이름의 파일로 따로 관리한다.

- `docs/history/<문서이름>.md`: 해당 문서(`docs/<문서이름>.md`)에 생긴 변경을 날짜순
  (최신 먼저)으로 기록한다. 각 항목은 날짜, 무엇을 바꿨는지, 왜 바꿨는지, 근거를 적는다.
- 본문(`docs/<문서이름>.md`)에는 "(2026-10-25 추가)"류 날짜 태그를 달지 않는다. 본문은
  항상 "현재 최선의 이해"만 담고, 그게 언제·왜 그렇게 됐는지는 이 history 파일이 설명한다.
- 새 분석/결정을 문서에 반영할 때는: 본문을 현재 상태로 깨끗하게 고치고, 이 history
  파일에 그 변경을 기록하는 두 단계로 나눠 작업한다.
- 예외: `TODO.md`처럼 문서 자체가 날짜순 진행 기록인 작업 트래커는 이 규칙 대상이 아니다.
